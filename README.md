# 抖音主页视频批量分析工具

粘贴一个抖音主页链接，自动完成：爬取全部已发布作品 → 下载无水印高清视频 → 本地离线语音转写口播逐字稿 → 导出 Excel。全程在你自己的电脑本地运行，数据不上传任何服务器。

---

## 一、怎么用（双击即可）

1. 进入本项目文件夹 `douyin-analyzer\`。
2. **双击 `启动工具.bat`**。
   - 第一次启动会自动创建虚拟环境并安装依赖，需要几分钟（会停在黑窗口里滚日志，属正常）。
   - 之后再启动会很快，约 3 秒后自动弹出浏览器。
3. 浏览器打开 `http://127.0.0.1:8000` 就是工具页面。
4. 把抖音主页链接粘进输入框 → （需要的话填 Cookie）→ 点「开始分析」。
5. 页面实时显示进度，跑完后点「下载 Excel」。
6. **用完后关掉那个黑色命令行窗口即停止服务。**

支持的主页链接形式：
- `https://www.douyin.com/user/MS4wLjABAAAA...`
- `https://v.douyin.com/xxxxxx/`（分享出来的短链）

## 二、抖音反爬与 Cookie 说明（重要）

抖音网页版有严格的反爬（签名校验 + 登录墙 + 滑块验证码），**这是本工具最大的不确定点**：

- **不填 Cookie**：也会尝试爬公开作品，但很容易被 403 拦截，或只拿到前几页就停。
- **填了登录后的 Cookie**：成功率高很多。获取方法见网页里的「如何获取 Cookie？」折叠说明：
  1. Edge/Chrome 打开 `douyin.com` 并登录你的账号；
  2. 按 `F12` → 切到「网络 / Network」→ 刷新页面；
  3. 随便点一个请求，在请求头里找到 `cookie:` 那一整行，复制冒号后面全部内容粘进网页 Cookie 框。
- **遇到验证码/登录墙**：先在浏览器里手动登录、滑过验证码，再回来重新提交；Cookie 有时效，失效后重新复制即可。
- **Web 端播放量（play_count）经常为 0 或不返回**：这是抖音网页接口本身的限制，不是 bug。此时 Excel 里播放量列留 0，点赞/评论/转发正常。

## 三、首次运行会自动下载语音识别模型

转写用的是开源模型 **faster-whisper**，默认模型名 `small`（约 460MB）。
- 第一次开始转写某个视频时，会自动从网络下载模型到本地缓存，**需要联网且较慢**，请耐心等。
- 想换更轻/更准的模型：改 `config.py` 里的 `ASR_MODEL_NAME`，可选 `tiny`（快但糙）/ `base` / `small`（默认）/ `medium`（准但慢很多）/ `large-v3`（最准最慢）。
- 转写在 CPU 上跑，`small` 模型大概 1 分钟视频要跑 0.5~2 分钟，页面会提示「这一步较慢」。

## 四、下载的文件在哪

```
douyin-analyzer\
├─ downloads\          ← 下载的视频，按编号命名 001.mp4、002.mp4……（与 Excel 编号严格对应）
├─ outputs\            ← 导出的 Excel（douyin_analysis_<任务号>.xlsx），网页也有下载按钮
└─ outputs\_raw_dump.jsonl   ← 调试用：每个作品的原始接口数据，出问题时可发来排查
```

Excel 列顺序：`编号 | 发布文案 | 口播文案 | 发布时间 | 播放量 | 点赞量 | 评论量 | 转发量 | 视频链接`
- 编号 N 对应 `downloads\0NN.mp4`（三位补零）。
- 发布时间已转成北京时间 `YYYY-MM-DD HH:MM`。
- 某个视频下载或转写失败时，整行不会让任务崩，口播列会标 `[失败] 原因`，继续处理下一个。

## 五、后续想上传到 GitHub 做成专属 Skill

代码已模块化，便于移植：

| 文件 | 职责 |
|---|---|
| `config.py` | 集中配置（模型名、目录、UA、超时） |
| `scraper.py` | f2 爬取主页作品 + 字段解析（已对字段名做兜底） |
| `downloader.py` | 无水印视频下载（aiohttp，控制文件名） |
| `asr.py` | faster-whisper 封装（模型懒加载、线程锁） |
| `excel_writer.py` | 导出 .xlsx |
| `main.py` | FastAPI 路由 + 后台任务 + 状态轮询 |
| `static/index.html` | 前端单页 |
| `probe.py` | 一次性探测脚本：dump f2 真实字段结构 |

上传前建议：删掉 `.venv\`、`downloads\`、`outputs\`、`__pycache__\`，加一个 `.gitignore`。
首次在新机器部署：装好 Python 3.12 后双击 `启动工具.bat` 即可自动建环境装依赖。

## 六、常见问题

- **端口被占**：改 `启动工具.bat` 和 `main.py` 里的 `8000` 为别的端口。
- **f2 升级后字段对不上**：先跑 `probe.py <主页URL>` 把 `_probe_out.json` 发来，按真实结构调 `scraper.py::parse_aweme`。
- **视频下载到有水印/损坏**：本工具优先用 `video.bit_rate[*].play_addr`（通常无水印），失败会回退 `download_addr`；个别视频若仍有水印，需结合 Cookie 重试。
